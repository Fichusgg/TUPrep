## Key ideas

- **Degree** = number of edges at a node. The sum of all degrees is twice the number of edges (handshake lemma).
- **Trees**: connected, no cycles; a tree with $n$ nodes has exactly $n-1$ edges and a unique path between any two nodes.
- **Shortest paths**: breadth-first search for unweighted graphs; with weights, repeatedly fix the closest unfixed node (Dijkstra).
- **Minimum spanning tree**: repeatedly take the cheapest edge that does not form a cycle (Kruskal).
- **Euler path** (every edge once) exists in a connected graph iff 0 or 2 nodes have odd degree. With 2 odd nodes, it starts at one and ends at the other.
- **Dependencies** (tasks with prerequisites) form a directed acyclic graph; a valid order is a topological order. The earliest finish time is the longest path.
- Counting paths in a grid or DAG: number of ways to reach a node = sum of the ways to reach its predecessors.

## Common traps

- Counting a shortest path by edges when the question wants total weight, or vice versa.
- Forgetting that a cheap edge can still be useless for a spanning tree if it closes a cycle.
- Treating a directed graph as undirected.
