## Key ideas

- A **proposition** is a statement that is either true or false. Build bigger ones with the connectives ¬ (not), ∧ (and), ∨ (inclusive or), ⊕ (exclusive or), → (implies) and ↔ (if and only if).
- **Precedence** (tightest first): ¬, ∧, ∨, →, ↔. So $p \land q \lor r$ means $(p \land q) \lor r$, and $p \to q \to r$ means $p \to (q \to r)$. When in doubt, add brackets.
- $p \to q$ is **false in exactly one row**: $p$ true and $q$ false. A false premise makes the implication (vacuously) true.
- A truth table for $n$ variables has $2^n$ rows. List them systematically (binary counting) so that you never miss a row.
- **Tautology**: true in every row. **Contradiction**: false in every row. **Contingency**: neither.
- Translating English: "but", "although" and "yet" all mean ∧. "Or" in logic is inclusive unless the text says "but not both". "If p, q" means $p \to q$; "q if p" also means $p \to q$.

## Common traps

- Reading "or" as exclusive. In the test, "or" is inclusive unless stated otherwise.
- Swapping the direction of an implication when the English puts the condition last ("q, if p").
- Forgetting that $p \to q$ is true whenever $p$ is false — students then count too few true rows.
- Writing $\neg p \land q$ when $\neg(p \land q)$ is meant: the ¬ binds tightly.
- Skipping rows in a truth table. Always write all $2^n$ rows before evaluating anything.
