## Key ideas

- **Binary**: each position is a power of two. $n$ bits give $2^n$ values (0 to $2^n-1$). One hex digit = 4 bits.
- **Bitwise** AND/OR/XOR act column by column; shifting left by $k$ multiplies by $2^k$.
- **Finite-state machines**: a set of states, a start state, transitions per input symbol, and accepting states. Trace the input one symbol at a time.
- **Parity / checksums**: a parity bit makes the number of 1s even (or odd); it detects any single flipped bit but cannot correct it.
- **Encodings**: run-length encoding, Caesar shifts, substitution tables — apply them mechanically and check the inverse.
- **Two's complement** (if needed): invert the bits and add one to negate.

## Common traps

- Reading binary from the wrong end.
- Forgetting leading zeros when the question fixes a bit width.
- In state machines, skipping a self-loop transition or reading the input in the wrong direction.
