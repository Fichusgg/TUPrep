## Key ideas

- Use a **trace table**: one column per variable, one row per executed line. Never keep values in your head.
- `x ← x + 1` evaluates the right-hand side with the *old* value first, then stores it.
- `for i from a to b` includes both ends; `while` re-checks its condition before every iteration and may run zero times; `repeat … until` always runs at least once.
- Arrays here are **1-indexed**: `A[1]` is the first element. `length(A)` is the number of elements.
- `a div b` is integer division (rounded down), `a mod b` is the remainder.
- Nested loops: the inner loop restarts completely for every iteration of the outer loop. Count iterations as a sum.
- Stacks are last-in-first-out (`push`/`pop`), queues first-in-first-out (`enqueue`/`dequeue`).

## Common traps

- Using an updated value too early when several assignments happen in a row (e.g. a swap without a temporary variable).
- Running a `for` loop one time too few or too many.
- Forgetting that a loop that modifies the array it reads sees the modified values in later iterations.
- Mixing up which element `pop` returns (the most recent one).
